# Basic HTML Portfolio Website

A simple portfolio website built using **only HTML**. This project demonstrates the fundamentals of HTML structure, semantic organization, tables, links, lists, images, and basic inline styling without using CSS files or JavaScript.

## 🚀 Features

- Simple navigation bar
- Personal introduction section
- Projects showcase
- Work experience section
- Education details
- Teacher reviews/testimonials
- Responsive-like table layout using HTML
- Clean and beginner-friendly code

## 🛠️ Technologies Used

- HTML5
- Inline CSS
